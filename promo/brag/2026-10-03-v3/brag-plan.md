# WaveLink v3 — data in motion

Direction: user's request for motion design like viral product videos. 22 seconds,
1920×1080, 30 fps. Music and SFX, no narration. Product grounding and the full
nine-question rubric are retained in source-grounding.md; the following supersedes
its quiet v2 creative direction and storyboard.

The hook is physical: SALESFORCE DATA arrives at oversized scale, then the word
MOVE and an export arrow launch the viewer into the product. Typography, camera,
and data objects carry the narrative. Avoid long static website shots.

| Time | Picture and motion | Readable payoff |
| --- | --- | --- |
| 0–3.3 | Masked type cascades; a giant arrow advances; the hook pushes into the query surface | Salesforce data. Ready to move. |
| 3.3–7.3 | Perspective editor lands, SOQL lines snap in; camera approaches the Run query button | Query: SELECT Name, Industry FROM Account LIMIT 3 |
| 7.3–11.2 | Camera pulls back; Results rows arrive as a fast cascade, then hold | Three fictional sample records |
| 11.2–14.2 | Rows fold together; a large CSV document lands beside kinetic EXPORT type | accounts.csv, 3 sample records |
| 14.2–18.0 | Document flies into a four-format fan; the fan resolves into a level row | CSV, JSON, Excel, XML |
| 18.0–22 | Logo lands on 18.56s; letter cascade resolves into a large stable wordmark | WaveLink. Local-first. Built for Salesforce. |

Motion vocabulary: masked waterfall typography, perspective-to-flat camera poses,
matched object handoffs, fast directional transitions, smooth long-tail settles.
No continual bouncing, no rapidly flashing screens, no invented performance stats.
Each message has a settled reading window. Final lockup holds to the final frame.

Music: local brag Happy Beats / Business Moves vol.12. Major cue locks at
8.74 (results), 13.11 (file), 18.56 (logo). Smaller entrances use its 0.55-second
beat grid where useful. Subtle bass response belongs to the product surface rim.
Clicks support Run query; soft impacts punctuate major object landings.

Actual source mark and source-grounded query/export labels are reused. The UI is
an enlarged motion-design reconstruction with fictional sample records, not a
live org recording or a speed benchmark. Deliver MP4, poster, caption, editable
source and verification locally.
