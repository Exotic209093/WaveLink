# Weekly metrics log

One row every Monday, taken from the Chrome Web Store developer dashboard and
GitHub Insights. WaveLink has no telemetry, so these figures come from store and
repo statistics only. The roadmap's v1.1 gate needs four consecutive weekly rows
and ten or more honest reviews; the growth target is **50 weekly users by
2026-12-31**.

Quote **weekly users**, not installs. Most historical installs are an automated
US ChromeOS trickle that never turns into users (see
[`launch-kit.md`](launch-kit.md#baseline-record-before-launch)).

## How to fill a row

| Column | Where to find it |
|---|---|
| Store version | Public listing → Version |
| Weekly users | Dashboard → Analytics → Users (weekly) |
| Impressions / listing views | Dashboard → Analytics → Impressions, last 7 days |
| Installs / uninstalls | Dashboard → Analytics → Installs & uninstalls, last 7 days |
| Reviews (avg) | Public listing → total reviews and average rating |
| Stars | GitHub repository stars |
| Repo views / uniques | GitHub → Insights → Traffic, last 14 days |
| Issues opened | New GitHub issues that week (bugs / feature requests) |
