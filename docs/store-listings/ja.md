## Description

```text
ログイン済みのブラウザタブから、Salesforceのデータを数秒でエクスポート。

WaveLinkは、Salesforceの管理者・開発者・コンサルタントのための無料のオープンソース・データワークスペースです。SOQLクエリを記述または作成し、レコードをプレビューして、必要な列を選び、CSV・Excel・JSON・XMLでダウンロードできます。Javaランタイムも、デスクトップ版Data Loaderのインストールも不要。データを第三者のサーバーに預けることもありません。

エクスポート

• 入力補完付きのSOQLエディタと、項目・条件・GROUP BY・集計に対応したビジュアルクエリビルダー
• 手軽なクエリはREST、大量データはBulk API 2.0で（進捗表示・キャンセル対応）
• 選んだ列だけをCSV・Excel（XLSX）・JSON・XMLで出力
• クエリを再利用可能なジョブとして保存し、ワンクリックで再実行

スナップショットと比較

• 主要オブジェクトのローカルスナップショットを定期実行
• 2つのファイル、2つのスナップショット、または接続済みの2つの組織を項目単位で比較

インポート

• 項目マッピング、検証、ドライランを備えたCSV・JSON・Excelのガイド付きインポート
• 本番組織への書き込み前に警告と確認入力を要求

高度な機能

• レコードインスペクター、オブジェクト・項目ブラウザー、REST/Tooling APIエクスプローラー、匿名Apex、API使用状況

設計段階からのプライバシー保護

WaveLinkには、分析・テレメトリー・広告・WaveLink独自のバックエンドは一切ありません。レコードはブラウザ内にとどまり、選択したSalesforce組織とのみやり取りされます。ソースコード: https://github.com/Exotic209093/WaveLink

既存のSalesforceブラウザセッションを使用します。WaveLinkは独立したツールであり、Salesforce, Inc.との提携関係や同社による承認はありません。
```
