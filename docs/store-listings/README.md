# Localised Chrome Web Store listings

WaveLink ships `_locales` for English (default) and the languages below. For
each one the store takes the **name** and **summary** from the package; paste
only the **description** in the dashboard (Store listing → language dropdown).
Screenshots can reuse the English set.

The in-app interface is English-only; these listings localise discovery.
The translations have not had native review, so have a native speaker skim
any listing you can.
