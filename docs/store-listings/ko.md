이미 로그인한 브라우저 탭에서 바로, 몇 초 만에 Salesforce 데이터를 내보내세요.

WaveLink는 Salesforce 관리자, 개발자, 컨설턴트를 위한 무료 오픈 소스 데이터 작업 공간입니다. SOQL 쿼리를 작성하거나 구성하고, 레코드를 미리 보고, 원하는 열을 선택해 CSV, Excel, JSON 또는 XML로 다운로드하세요. Java 런타임도, 데스크톱 Data Loader 설치도 필요 없으며, 데이터를 보관하는 타사 서버도 없습니다.

내보내기

• 자동 완성을 지원하는 SOQL 편집기와 필드, 필터, GROUP BY, 집계를 위한 시각적 쿼리 빌더
• 빠른 쿼리는 REST로, 대용량 개체는 Bulk API 2.0으로 (진행 상황 표시 및 취소 지원)
• 선택한 열만 CSV, Excel(XLSX), JSON 또는 XML로 내보내기
• 쿼리를 재사용 가능한 작업으로 저장하고 클릭 한 번으로 다시 실행

스냅샷 및 비교

• 주요 개체의 로컬 스냅샷을 정기적으로 예약
• 두 파일, 두 스냅샷 또는 연결된 두 조직을 필드 단위로 비교

가져오기

• 필드 매핑, 유효성 검사, 시험 실행을 갖춘 CSV, JSON, Excel 가져오기 마법사
• 쓰기 작업 전 운영 환경 경고 및 확인 문구 입력

고급 기능

• 레코드 검사기, 개체 및 필드 브라우저, REST/Tooling API 탐색기, 익명 Apex, API 사용량

설계 단계부터 개인정보 보호

WaveLink에는 분석, 원격 측정, 광고, WaveLink 자체 백엔드가 없습니다. 레코드는 브라우저에 남아 있으며 사용자가 선택한 Salesforce 조직과만 주고받습니다. 소스 코드: https://github.com/Exotic209093/WaveLink

기존 Salesforce 브라우저 세션을 사용합니다. WaveLink는 독립적인 도구이며 Salesforce, Inc.와 제휴하거나 Salesforce, Inc.의 보증을 받지 않았습니다.
