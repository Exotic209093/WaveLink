## Description

```text
Sortez vos données Salesforce en quelques secondes, directement depuis l'onglet où vous êtes déjà connecté.

WaveLink est un espace de travail de données gratuit et open source pour les administrateurs, développeurs et consultants Salesforce. Rédigez ou construisez une requête SOQL, prévisualisez les enregistrements, choisissez vos colonnes et téléchargez en CSV, Excel, JSON ou XML. Pas d'environnement Java, pas d'installation de Data Loader, aucun serveur tiers qui détient vos données.

EXPORT

• Éditeur SOQL avec autocomplétion et générateur visuel de requêtes pour les champs, filtres, GROUP BY et agrégats
• REST pour les requêtes rapides, Bulk API 2.0 pour les gros objets, avec suivi de progression et annulation
• CSV, Excel (XLSX), JSON ou XML avec uniquement les colonnes choisies
• Enregistrez vos requêtes comme tâches réutilisables et relancez-les en un clic

INSTANTANÉS ET COMPARAISON

• Planifiez des instantanés locaux récurrents de vos objets clés
• Comparez deux fichiers, deux instantanés ou deux orgs connectées, champ par champ

IMPORT

• Import guidé de fichiers CSV, JSON et Excel avec mappage des champs, validation et simulation
• Avertissements en production et confirmation saisie avant toute écriture

AVANCÉ

• Record Inspector, explorateur d'objets et de champs, explorateur d'API REST/Tooling, Apex anonyme et suivi de la consommation d'API

CONFIDENTIALITÉ DÈS LA CONCEPTION

WaveLink n'a ni analytique, ni télémétrie, ni publicité, ni serveur WaveLink. Vos enregistrements restent dans votre navigateur et ne sont échangés qu'avec les orgs Salesforce que vous sélectionnez. Code source : https://github.com/Exotic209093/WaveLink

Utilise votre session Salesforce déjà ouverte dans le navigateur. WaveLink est indépendant et n'est ni affilié à Salesforce, Inc. ni approuvé par celle-ci.
```
