## Description

```text
Esporta i tuoi dati Salesforce in pochi secondi, direttamente dalla scheda del browser in cui hai già effettuato l'accesso.

WaveLink è uno spazio di lavoro per i dati gratuito e open source per amministratori, sviluppatori e consulenti Salesforce. Scrivi o componi una query SOQL, visualizza l'anteprima dei record, scegli le colonne e scarica in CSV, Excel, JSON o XML. Niente runtime Java, nessuna installazione di Data Loader, nessun server di terze parti che custodisce i tuoi dati.

ESPORTAZIONE

• Editor SOQL con completamento automatico e generatore visuale di query per campi, filtri, GROUP BY e aggregazioni
• REST per le query rapide, Bulk API 2.0 per gli oggetti di grandi dimensioni, con avanzamento e annullamento
• CSV, Excel (XLSX), JSON o XML con le sole colonne che scegli
• Salva le query come job riutilizzabili e rieseguile con un clic

SNAPSHOT E CONFRONTO

• Pianifica snapshot locali ricorrenti degli oggetti principali
• Confronta due file, due snapshot o due org collegate, campo per campo

IMPORTAZIONE

• Importazione guidata di CSV, JSON ed Excel con mappatura dei campi, convalida e simulazione
• Avvisi per la produzione e conferma digitata prima di ogni scrittura

AVANZATE

• Record Inspector, browser di oggetti e campi, explorer delle API REST/Tooling, Apex anonimo e utilizzo delle API

PRIVACY FIN DALLA PROGETTAZIONE

WaveLink non ha analisi, telemetria, pubblicità né un backend WaveLink. I tuoi record restano nel browser e vengono scambiati solo con le org Salesforce che selezioni. Codice sorgente: https://github.com/Exotic209093/WaveLink

Usa la sessione Salesforce già aperta nel browser. WaveLink è indipendente e non è affiliato né approvato da Salesforce, Inc.
```
