## Description

```text
Tire seus dados do Salesforce em segundos, direto da aba do navegador em que você já está conectado.

O WaveLink é um espaço de trabalho de dados gratuito e de código aberto para administradores, desenvolvedores e consultores Salesforce. Escreva ou monte uma consulta SOQL, visualize os registros, escolha as colunas e baixe em CSV, Excel, JSON ou XML. Sem Java, sem instalar o Data Loader e sem servidores de terceiros guardando seus dados.

EXPORTAÇÃO

• Editor SOQL com preenchimento automático e construtor visual de consultas para campos, filtros, GROUP BY e agregações
• REST para consultas rápidas e Bulk API 2.0 para objetos grandes, com progresso e cancelamento
• CSV, Excel (XLSX), JSON ou XML apenas com as colunas que você escolher
• Salve consultas como trabalhos reutilizáveis e execute-as novamente com um clique

SNAPSHOTS E COMPARAÇÃO

• Agende snapshots locais recorrentes dos objetos principais
• Compare dois arquivos, dois snapshots ou duas orgs conectadas, campo a campo

IMPORTAÇÃO

• Importação guiada de CSV, JSON e Excel com mapeamento de campos, validação e simulação
• Avisos de produção e confirmação digitada antes de qualquer gravação

AVANÇADO

• Record Inspector, navegador de objetos e campos, explorador de API REST/Tooling, Apex anônimo e uso de API

PRIVACIDADE DESDE A CONCEPÇÃO

O WaveLink não tem análises, telemetria, anúncios nem servidor próprio. Seus registros ficam no seu navegador e são trocados apenas com as orgs Salesforce que você selecionar. Código-fonte: https://github.com/Exotic209093/WaveLink

Usa a sessão do Salesforce já aberta no navegador. O WaveLink é independente e não é afiliado nem endossado pela Salesforce, Inc.
```
