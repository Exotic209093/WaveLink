## Description

```text
Salesforce-Daten in Sekunden exportieren – direkt aus dem Browser-Tab, in dem Sie bereits angemeldet sind.

WaveLink ist ein kostenloser Open-Source-Datenarbeitsbereich für Salesforce-Administratoren, -Entwickler und -Berater. Schreiben oder erstellen Sie eine SOQL-Abfrage, prüfen Sie die Datensätze in der Vorschau, wählen Sie Ihre Spalten und laden Sie CSV, Excel, JSON oder XML herunter. Keine Java-Laufzeitumgebung, keine Data-Loader-Installation, kein fremder Server, der Ihre Daten speichert.

EXPORT

• SOQL-Editor mit Autovervollständigung und visueller Query-Builder für Felder, Filter, GROUP BY und Aggregate
• REST für schnelle Abfragen, Bulk API 2.0 für große Objekte – mit Fortschrittsanzeige und Abbruch
• CSV, Excel (XLSX), JSON oder XML mit genau den Spalten, die Sie auswählen
• Abfragen als wiederverwendbare Jobs speichern und mit einem Klick erneut ausführen

SNAPSHOTS UND VERGLEICH

• Regelmäßige lokale Snapshots wichtiger Objekte planen
• Zwei Dateien, zwei Snapshots oder zwei verbundene Orgs Feld für Feld vergleichen

IMPORT

• Geführter Import von CSV, JSON und Excel mit Feldzuordnung, Validierung und Probelauf
• Produktionswarnungen und Bestätigung per Texteingabe vor jedem Schreibvorgang

ERWEITERT

• Record Inspector, Objekt- und Feldbrowser, REST/Tooling-API-Explorer, Anonymous Apex und API-Nutzung

DATENSCHUTZ VON ANFANG AN

WaveLink hat keine Analyse, keine Telemetrie, keine Werbung und kein WaveLink-Backend. Ihre Datensätze bleiben in Ihrem Browser und werden nur mit den von Ihnen ausgewählten Salesforce-Orgs ausgetauscht. Quellcode: https://github.com/Exotic209093/WaveLink

Verwendet Ihre bestehende Salesforce-Browsersitzung. WaveLink ist unabhängig und weder mit Salesforce, Inc. verbunden noch von Salesforce, Inc. unterstützt.
```
